<p align="center"><b>Shoot and eliminate your foes with accurate feedback. Hitmarkers is a simple mod that adds visual/auditory feedback to any hit or kill you make, making for very satisfying combat!</b></p>

## Installation:
Simply drag and drop both the Mods and UserData folders into your BONELAB/BONEWORKS directory.\
**If you are on Quest**, drag and drop those folders into ***MelonLoader/com.StressLevelZero.BONELAB***.

## Custom Sounds:
1. Bring over any sound you'd like
2. Name the sound either "marker_NUMBER" or "finisher_NUMBER"
3. You're done

## Custom Textures:
1. Create a copy of the "Default" folder in your Skins directory.
2. Rename the copy of the folder to whatever you want the hitmarker to be.
3. Create a hitmarker, finisher, and finisher feedback texture.
4. Make sure the texture is in powers of two! (i.e. 256, 512, 1024)*
5. Name the file accordingly. If it's a hitmarker, name it "marker.png." If it's a finisher, name it "finisher_marker.png." For the feedback skull, "finisher_feedback.png."
6. You're done!
